# OOL Racing credits

OOL Racing is a playable web port built on **[BKcore/HexGL](https://github.com/BKcore/HexGL)** by Thibaut Despoulain (BKcore).

The HexGL repository is MIT licensed. This project keeps and ships its original code and assets, including the Feisar ship, Cityscape track, geometry, textures, sound effects, and the Three.js 50dev runtime. The original repository and license are preserved in `hexgl-original/` and `LICENSE`.

Additional OOL Racing work adds the launcher UI, mobile touch/tilt controls, websim leaderboard records, and network ghost replay layer.
